Salin Kode Tools

Tekan Ctrl+A lalu Ctrl+C • Paste ke Notepad • Simpan sebagai .html

Cara Simpan Tools

1. Klik Copy Kode Tools di sidebar
2. Buka Notepad (Win) / TextEdit (Mac)
3. Paste (Ctrl+V / Cmd+V)
4. File → Save As → pilih All Files
5. Nama file: minimale-studio.html
6. Double-click → buka di Chrome ✓
💡 Setelah itu tinggal double-click file kapanpun. Masukkan API key sekali, tersimpan permanen.
